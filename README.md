# VIDEO AI - MCP TEST

## 1. Mục đích

Kho tài liệu thử nghiệm kết nối MCP phục vụ
hệ thống sản xuất video AI.

## 2. Mục tiêu thực hành

- Kết nối AI với kho tài liệu GitHub.
- Tìm kiếm và đọc tài liệu thông qua MCP.
- Truy xuất thông tin nhân vật và bối cảnh.
- Tạo Prompt dựa trên tài liệu đã truy xuất.
- Kiểm tra tính nhất quán của nhân vật.

## 3. Danh sách tài liệu dự kiến

- CHARACTER_BIBLE.md: Hồ sơ nhân vật.
- ENVIRONMENT_BIBLE.md: Hồ sơ bối cảnh.
- SCRIPT.md: Kịch bản video.
- STORYBOARD.md: Bảng phân cảnh.
- PROMPT_LIBRARY.md: Thư viện Prompt.

## 4. Quy tắc sử dụng

- Chỉ sử dụng dữ liệu mẫu.
- Không chứa thông tin cá nhân hoặc bí mật.
- Ưu tiên quyền truy cập chỉ đọc khi kết nối MCP.
- Không tự suy diễn thông tin còn thiếu.

## 5. Trạng thái

Đang xây dựng kho tài liệu thử nghiệm.
Chưa kết nối MCP Server.
